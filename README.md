# 🚚 Sistema de Logística de Entregas

## 📋 Sobre o Projeto

Sistema de gestão de entregas desenvolvido em Java com JDBC e Maven, simulando o gerenciamento de uma empresa de e-commerce. A aplicação oferece funcionalidades completas de CRUD para clientes, motoristas, pedidos e entregas, além de relatórios analíticos para tomada de decisão.

---

## 🎯 Objetivo

Desenvolver uma aplicação Java via terminal que demonstra na prática o uso de JDBC para persistência de dados, seguindo as melhores práticas de arquitetura em camadas e modelagem relacional.

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Descrição |
|------------|-----------|
| **Java 17+** | Linguagem de programação |
| **Maven** | Gerenciamento de dependências |
| **JDBC** | Conexão com banco de dados |
| **MySQL** | Banco de dados relacional |
